# Structure de Cuisine — prototype direction JF

Prototype statique indépendant inspiré du rythme visuel fourni par JF : espaces éditoriaux très aérés, scènes produit sombres avec profondeur violette, preuves terrain compactes et orange SDC utilisé comme signature.

## Sécurité du déploiement

- aucun fichier du site IONOS actuel n’est modifié;
- aucun `CNAME` n’est inclus;
- aucune redirection DNS n’est demandée;
- le prototype est conçu pour un dépôt GitHub Pages distinct;
- tous les liens d’action restent des liens de test vers l’adresse SDC.

## Aperçu local

Ouvrir `index.html` ou servir le dossier avec un serveur HTTP statique.
